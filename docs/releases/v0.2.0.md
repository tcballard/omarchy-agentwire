# omarchy-agentwire v0.2.0

This release moves the widget onto Omarchy's current Quattro panel contract and
AgentWire's bounded inspector summary API v1.

Highlights:

- accurate live, served-trace, and completed lifecycle states;
- lower-cost polling without downloading full trace histories;
- strict numeric-loopback configuration and response validation;
- keyboard navigation and horizontal/vertical bar support;
- deterministic archives and pinned compatibility gates.

Install or update with:

```bash
omarchy plugin add https://github.com/tcballard/omarchy-agentwire.git --enable
```

Requires an AgentWire build containing inspector summary API v1. See the README
for the Git installation command and the release runbook for compatibility
details.
