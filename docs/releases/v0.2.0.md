# omarchy-agentwire v0.2.0

This release moves the widget onto Omarchy's current Quattro service and panel
contracts and AgentWire's stable inspector hub.

Highlights:

- accurate live, served-trace, and completed lifecycle states;
- zero-setup native operation with a bundled, pinned AgentWire runtime;
- an automatically managed loopback hub and private XDG state;
- lower-cost polling without downloading full trace histories;
- strict numeric-loopback configuration and response validation;
- keyboard navigation and horizontal/vertical bar support;
- deterministic archives and pinned compatibility gates.

Install or update with:

```bash
omarchy plugin add https://github.com/tcballard/omarchy-agentwire.git --enable
```

No separate AgentWire, Cargo, systemd, URL, or PATH setup is required on
x86-64 Omarchy. See the README for recording usage and the release runbook for
compatibility details.
