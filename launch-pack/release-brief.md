# Release brief

omarchy-agentwire v0.2.0 is a compatibility and trust release: it adopts the
current Quattro panel entry point and a small versioned AgentWire endpoint.
Users get clearer lifecycle states, cheaper polling, keyboard controls, and
explicit local-response safeguards.

Audience: AgentWire users running Omarchy 4.0.0, 4.0.1, or a compatible current
Quattro shell build.
